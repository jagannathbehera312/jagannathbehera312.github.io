## 🌐 Deploy to GitHub Pages (Free, 1-Minute Setup)

1. Initialize git in the folder:
   ```bash
   git init
   git add .
   git commit -m "Update portfolio for Akamai Technologies SDET-II role"
   ```
2. Create a repository on GitHub named `jagannathbehera312.github.io` (or `portfolio`).
3. Push to GitHub:
   ```bash
   git branch -M main
   git remote add origin https://github.com/jagannathbehera312/jagannathbehera312.github.io.git
   git push -u origin main
   ```
4. In GitHub repository **Settings -> Pages**, set source branch to `main` -> Save.
5. Your live portfolio will be instantly live at `https://jagannathbehera312.github.io`!
